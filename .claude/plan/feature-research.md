# Debugtron Tauri 功能扩展深度调研与创新方案

> **调研范围**：开发体验提升 + 深度调试能力 + 团队协作功能 + 生产环境调试
>
> **产出目标**：功能创意列表 + 详细实施路线图 + 竞品分析 + MVP 功能集设计

---

## 执行摘要

基于对现有代码、Chrome DevTools Protocol、竞品工具和开发者工作流的深度调研，本报告提出了 **50+ 个功能创意**，涵盖 4 个核心维度。关键发现：

- **技术储备充分**：Tauri + Rust + tokio 架构完全支持高级功能扩展
- **市场定位清晰**：唯一提供"自动发现 + 一键调试"的工具，有明确差异化优势
- **增长机会巨大**：当前覆盖基础调试需求 70%，团队协作 20%，自动化 0%
- **快速胜利可见**：10 个功能可在 1-2 周内实现，立即提升 30% 用户体验

| **消息流可视化** | 时序图展示主↔渲染通信 | ⭐⭐⭐ 高 | ⭐⭐⭐⭐⭐ | P0 |
| **消息延迟分析** | 记录每个消息的耗时 | ⭐⭐ 中 | ⭐⭐⭐⭐ | P1 |
| **IPC 回放** | 记录并回放 IPC 消息序列 | ⭐⭐⭐⭐ 很高 | ⭐⭐⭐⭐ | P2 |
| **超时检测** | 自动检测未响应的消息 | ⭐⭐ 中 | ⭐⭐⭐⭐ | P1 |

**市场机会**：Devtron 曾提供 IPC Monitor 但已废弃，这是 **完全空白的市场**。

**实施方案**：
```javascript
// 注入代码到应用（通过 --require）
const originalHandle = ipcMain.handle;
ipcMain.handle = function(channel, listener) {
  return originalHandle.call(this, channel, async (...args) => {
    const startTime = Date.now();
    debugtron.sendIpcEvent('ipc-call', { channel, args, type: 'main' });
    const result = await listener(...args);
    const duration = Date.now() - startTime;
    debugtron.sendIpcEvent('ipc-response', { channel, result, duration });
    return result;
  });
};
```

## 第六部分：关键技术决策

### 决策 1：CDP 集成架构

**问题**：如何高效管理多个 WebSocket 连接？

**方案 A**：每个调试目标独立连接
```rust
struct CdpClient {
    ws: WebSocketStream,
    target_id: String,
}
```
- 优点：隔离性好
- 缺点：连接数多

**方案 B**：单连接多路复用
```rust
struct CdpManager {
    ws: WebSocketStream,
    sessions: HashMap<SessionId, SessionData>,
}
```
- 优点：资源占用少
- 缺点：复杂度高

**推荐**：方案 A（简单可靠，性能足够）

---

### 决策 2：IPC Hook 实现

**问题**：如何 Hook ipcMain/ipcRenderer？

**方案 A**：--require 注入脚本
```bash
electron --require ./debugtron-hook.js
```
- 优点：非侵入式
- 缺点：用户需要修改启动命令

**方案 B**：修改应用代码（不可行）
- 缺点：侵入性太强

**方案 C**：Proxy 拦截（推荐）
```javascript
const originalIpcMain = require('electron').ipcMain;
const proxiedIpcMain = new Proxy(originalIpcMain, {
  get(target, prop) {
    if (prop === 'handle') {
      return function(...args) {
        // Hook logic
        return target.handle.apply(target, args);
      };
    }
    return target[prop];
  }
});
module.exports = { ipcMain: proxiedIpcMain };
```

**推荐**：方案 A + 方案 C 结合
